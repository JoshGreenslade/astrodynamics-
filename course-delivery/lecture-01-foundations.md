# Lecture 01: Foundations Kickoff

## Date
2026-06-14

## Status
In progress

## Learning objectives
- Re-activate prerequisite vector and unit analysis skills.
- Introduce Newtonian gravitation as the basis for astrodynamics.
- Set up the two-body assumptions used throughout Stage 1.

## Lecture outline
1. Activation task: unit consistency and vector decomposition warm-up.
2. Worked derivation: inverse-square gravitational force and acceleration form.
3. Guided example: convert a state description into scalar/vector components.
4. Independent practice: short conic-geometry concept check.

## Formative assessment (exit ticket)
- Prompt 1: State the two-body assumptions and one practical limitation.
- Prompt 2: Compute gravitational acceleration magnitude at a given radius.
- Success criteria: correct setup, unit consistency, and interpretation.

## Follow-up remediation plan
- Re-teach unit handling and vector projection in a short starter next session for students who miss Prompt 2.
